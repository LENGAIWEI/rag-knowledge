#10. Redis 知识库
## 1. Redis 概述
**内存型 Key-Value 非关系数据库**，单线程模型（命令执行单线程，IO 多线程），高性能。
用途：缓存、分布式锁、计数器、限流、消息队列、排行榜。
## 2. 常用数据类型
- String：字符串，可存数字，incr 自增
- List：双向链表，栈 / 队列
- Set：无序集合，去重，交集并集
- ZSet：有序集合，排行榜
- Hash：哈希，适合对象存储
- Bitmap、HyperLogLog、Geo
## 3. 持久化机制
- RDB：快照，定时保存全量数据到磁盘；速度快，故障会丢失最近数据
- AOF：追加日志，记录每条写命令；数据更安全，文件体积大；可 AOF+RDB 混合持久化
## 4. 缓存三大问题
1. 缓存穿透：查询不存在数据，绕过缓存打数据库；解决：布隆过滤器、空值缓存
2. 缓存击穿：热点 key 过期，大量请求打数据库；解决：互斥锁、永不过期
3. 缓存雪崩：大量 key 同时过期，数据库压力瞬间打爆；解决：过期时间加随机值、集群、多级缓存
## 5. 分布式锁
Redis 实现分布式锁：SET key value NX EX
NX：不存在才设置；EX 设置过期时间。
问题：锁超时、主从切换锁丢失；推荐 Redlock，生产优先 Redisson。
## 6. 过期删除策略
惰性删除（访问时判断过期）+ 定期删除（后台抽样扫描）；内存满触发淘汰策略。
内存淘汰策略：LRU、LFU、随机、ttl 等。
## 7. 主从 & 哨兵 & 集群
- 主从复制：主节点写，从节点读，数据同步；一主多从
- 哨兵 Sentinel：监控主从，主宕机自动故障转移
- Redis Cluster 集群：分片，16384 槽位，多主多从，横向扩容
## 8. SpringBoot 整合 Redis
starter：spring-boot-starter-data-redis，默认 Lettuce 客户端。
RedisTemplate 操作 Redis；序列化默认 JDK 序列化，生产建议使用 Jackson 序列化。
## 9. 面试问答
Q：缓存穿透击穿雪崩区别？
A：穿透查不存在数据；击穿热点 key 过期；雪崩大量 key 同时过期。
Q：Redis 单线程为什么快？
A：命令执行单线程，避免锁竞争；内存操作，IO 多路复用，协议简单。
